Privacy Policy

Genius Gym · Last updated 27 November 2026

Genius Gym is a personal tool operated by Aseem Bhalla to upload and schedule Shorts to YouTube channels he owns. This policy explains what data it accesses and how that data is handled.

Data accessed

When a channel owner signs in with Google and grants permission, Genius Gym requests these scopes:

  • youtube.upload: to upload new videos to the connected channel and set their title, description, tags, category, privacy status, scheduled publish time, and audience (made-for-kids) setting.
  • youtube.readonly: to read the connected channel's name, so the tool can confirm it is uploading to the intended channel and stop if it is not.

Genius Gym can upload videos, which change the connected YouTube channel by adding new (initially private, scheduled) videos to it. It does not delete videos, and it does not access email, contacts, Drive files or any other Google data.

How data is used

The data is used only to upload and schedule the channel owner's own videos to the owner's own channels. The only information kept is the ID of each video uploaded, so the same video is never uploaded twice. This is stored in a private repository accessible only to the owner.

Sharing

Data is not sold, rented, shared with third parties, or used for advertising. It is not used to train generalised AI or machine-learning models.

Storage and retention

Access credentials are stored as encrypted secrets and are never published. The list of uploaded video IDs is kept in the owner's private repository until the owner deletes it.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, or through the Google security settings page. After revocation, no further uploads can be made.

Google API Services

Genius Gym's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Genius Gym uses YouTube API Services; by using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
